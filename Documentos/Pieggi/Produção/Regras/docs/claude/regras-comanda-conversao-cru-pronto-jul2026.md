# PADRÃO PIEGGI — CONVERSÃO PESO CRU × PESO PRONTO (ALMOÇO E JANTAR)
**Regra nova, Bruno — jul/2026. Manual único de conversão. O Claudinho NÃO pensa: aplica o fator.**

## Regra geral (obrigatória)
Em toda programação/comanda de almoço e jantar, **sempre mostrar os DOIS**:
- ✔ **Peso pronto** (produção / o que é servido)
- ✔ **Peso cru** (compra / produção)
- ❌ **Nunca só um dos dois.**

O peso da programação é o **peso pronto**. O Claudinho calcula o **peso cru** automaticamente aplicando o fator sobre o pronto.

## SOBREMESAS
Servido **60 g/pax cada** (ou o que a programação trouxer). **Produzir sempre +20%.** Ex.: 1 kg servido → produzir 1,20 kg.

## FRUTAS LAMINADAS
Servido **50 g/pax** → **comprar 60 g/pax**. (Almoço/jantar = sem favo.)
